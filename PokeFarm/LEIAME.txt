POKEFARM - lives da Kick/Twitch + Pokeidle 24h, com alertas do mercado (Mac e Windows)

PRECISA: Node.js 22 ou mais novo (https://nodejs.org). No Terminal/Prompt, dentro desta pasta:

  npm install          (só na primeira vez)
  npm start            abre o app direto, sem gerar instalador

GERAR O APP:
  npm run dist:mac     -> dist/PokeFarm-3.0.0-arm64.dmg e -x64.dmg   (rodar no Mac)
  npm run dist:win     -> dist/PokeFarm-Setup-3.0.0.exe (instalador)
                          dist/PokeFarm-Portable-3.0.0.exe (sem instalar)
                          Rode no Windows. No Mac só funciona com o Wine instalado:
                          brew install --cask wine-stable
  Sem Windows à mão: suba a pasta KickMulti para o GitHub e rode
  Actions > "PokeFarm build" > Run workflow. Ele gera o .dmg e o .exe.

PRIMEIRA ABERTURA (app sem assinatura paga):
  Mac:     botão direito no PokeFarm > Abrir.
  Windows: "O Windows protegeu o computador" > Mais informações > Executar assim mesmo.

USO:
- Lives: escolha Kick/Twitch, digite o canal ou cole o link e dê Enter.
- Cada bloco: arraste o título para mover; borda direita = largura, borda de baixo = altura,
  canto = os dois. O botão de grade volta tudo para a grade.
- Menu Entrar: login na Twitch/Kick (vale para todos os blocos). Depois clique em ⟳.
- Aba Pokeidle: o jogo fica rodando mesmo nas outras abas.
- Aba Alertas: regras por nome, preço máximo, % abaixo da média e shiny. Só avisa, nunca compra.
- O computador não dorme com o app aberto, inclusive com a tela bloqueada.
  No notebook, deixe na tomada e não feche a tampa (sem monitor externo ele dorme).
